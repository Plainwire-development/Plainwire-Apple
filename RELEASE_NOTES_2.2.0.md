# Plainwire Apple 2.2.0

Animated GIF avatars, profile banners, server banners, and message images now play in the native client. GIF and APNG frames decode in the background at the displayed size and retain their timing. A shared, bounded cache reuses downloads and decoded frames; native image layers animate without rebuilding chat rows. Playback pauses offscreen, while the app is inactive, with Reduce Motion, or when Settings → Chat → Autoplay animated media is off. Profile editing accepts image URLs as well as uploads, including GIFs. The native GIF picker searches the selected server’s configured provider, supports pagination, and inserts an attachment into the draft. GIF search and share registration use the same authenticated API as the web client; no provider key is stored in the app. The attachment menu also offers Markdown formatting shortcuts.

Use **Switch Server Host…** from the sign-in screen, connection recovery, account menu, app menu, or Settings → Connection to connect to a self-hosted Plainwire installation. The host persists after relaunch and recent hosts are available in the picker. HTTPS domains, custom ports, and API deployment paths are accepted; local installations can use HTTP. Switching ends calls and signs out of the previous host, rebuilds HTTP/realtime/calling/web-tool connections, clears private media and room state, and keeps drafts separately for each host and account. Cookies from an old installation are removed even when both databases use the same hostname on different ports. Shared invites, conversation links, activity, and media use the selected host.

Mac Settings now uses native tabs and grouped forms. The sidebar uses system selection and provides an account/status menu; chat uses a quiet system background and respects Reduce Transparency. Unchanged message rows avoid unnecessary rebuilding. New chat controls include Enter-to-send versus Command-Return, animation autoplay, clearing local drafts, and per-conversation notification muting on this device. Status changes are also available in the profile editor and Mac account menu.

The reference web client was compared at `/Users/robertnelson/Plainwire` (the Mac equivalent of `/home/robert/Plainwire`). Existing native messaging, search, replies, reactions, forwarding, pins, groups, friends, activity, uploads, voice notes, server management, and WebRTC calling remain available. Forums, Source Hub, developer apps, and advanced server tools continue through the authenticated web tools on the selected host. Full native coverage of those advanced web tools and iOS background calling/push are not part of this release.

Validation: 55 portable core tests, repository/version checks, native WebRTC and call-panel interaction tests, generated GIF frame/timing/downsampling/playback tests, and integration tests using two independent localhost installations with identical user IDs. The integration checks cover host cookies, media invalidation, draft isolation/restoration, GIF search/insertion, stale sign-in responses, native settings/sidebar/host-picker rendering, and actual AppKit Return/Command-Return events in both send modes. macOS and iOS Simulator builds are verified before tagging. Real-device calls, accessibility interaction, and a production self-hosted deployment still need hands-on testing.
